# Визуальная проверка COFFEEMAN

В задании доступен один концепт размером 1280 × 844 с двенадцатью экранами. Ширина корпуса телефона на нём около 204 пикселей. Для сравнения с браузером на ширине 390 CSS-пикселей геометрию оценивали с коэффициентом около 1,9. Ориентиры концепта в этом масштабе включают боковые отступы около 17–21 CSS-пикселя, скругления панелей около 15–23 CSS-пикселей и компактную четырёхсекционную навигацию. Время, батарея, рамка телефона и внешние подписи входят в иллюстрацию. Отдельные оригинальные скриншоты iiko не были предоставлены.

## Корректировки после первого прогона

- В карточке блюда при ширине 375 CSS-пикселей действие «Добавить» находилось ниже видимой части панели. Параметры собраны в компактные раскрывающиеся строки, а основное действие закреплено внизу. Повторный сценарий проверяет, что кнопка практически полностью видна при каждом размере экрана.
- Быстрые действия перемещены вправо и вверх до пропорций концепта. Подложка размывается, а синяя кнопка закрытия расположена отдельно внизу. При открытом меню скрывается плавающая кнопка создания заказа.
- Вкладка остатка «В наличии» занимала две строки на телефоне. Отступы уменьшены для четырёх вкладок одной высоты.
- В админской форме товара действие «Сохранить» было частично скрыто при открытии. Заголовок и действия закреплены, а поля прокручиваются между ними.
- Сетка меню использует три колонки по тексту задания. В приложенном концепте категории показаны в двух колонках. Названия в рабочем каталоге берутся из данных, а фото показываются только при наличии ссылки на изображение.

## Воспроизведение

Для проверки нужна установленная версия Chromium. Playwright использует `/usr/bin/chromium`, если он есть. На остальных системах можно установить браузер через `npx playwright install chromium`.

```sh
npm ci
npm run build
QA_PREVIEW=1 VISUAL_CHECK=1 npm run test:e2e -- --project=chromium-mobile
```

Сохранены 160 PNG, по 32 кадра при 375 × 812, 390 × 844, 393 × 852, 430 × 932 и 768 × 1024 CSS-пикселях. Сценарий проверяет ширину документа и минимальный размер текста в видимых полях ввода на каждом кадре. Базовый запуск без `VISUAL_CHECK` прогоняет функциональные сценарии. Для прогона WebKit установите `npx playwright install --with-deps webkit` и задайте `QA_WEBKIT=1`. Мобильные размеры и уменьшение видимой высоты имитируются в браузере. Проверка на физических устройствах остаётся отдельным шагом.
