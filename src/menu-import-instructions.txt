COFFEEMAN — подготовка меню для импорта

Передайте этот файл и исходное меню помощнику с искусственным интеллектом. Меню можно приложить как текст, таблицу, PDF или читаемые фотографии. Скопируйте ответ помощника целиком в «Каталог → Импорт меню» в COFFEEMAN.

ИНСТРУКЦИЯ ДЛЯ ИСКУССТВЕННОГО ИНТЕЛЛЕКТА

Извлеки категории, блюда и цены из приложенного меню. Верни один корректный JSON-объект без пояснений, Markdown, комментариев и запятых после последнего элемента.

Пример структуры. Используй данные из приложенного меню вместо значений в примере:

{
  "categories": [
    { "name": "Кофе", "color": "#357AFE" },
    { "name": "Десерты" }
  ],
  "products": [
    {
      "name": "Капучино",
      "category": "Кофе",
      "price": 190,
      "volume": "250 мл",
      "description": "Эспрессо и молоко"
    },
    {
      "name": "Чизкейк",
      "category": "Десерты",
      "price": 290,
      "quantity": 5,
      "min": 2
    }
  ]
}

Правила:
- Для каждого блюда обязательны name (название), category (категория) и price (цена в рублях).
- Указывай цену числом без валюты. Для дробной части используй точку, например 190.50.
- Название категории в поле category должно совпадать с названием в categories. Раздел categories можно опустить: категории создаются из названий в блюдах.
- Для категории обязателен name. Дополнительный color задаётся шестью шестнадцатеричными цифрами с префиксом #.
- Дополнительные поля блюда: description (описание), volume (размер или объём), imageUrl (прямая ссылка HTTP или HTTPS на фото), quantity (целый неотрицательный остаток), min (целый неотрицательный порог), available (true или false).
- Опускай неизвестные дополнительные поля. Ссылка на фотографию допустима, если она есть в исходных материалах. Без quantity или при quantity: null количественный учёт отключён. При отсутствии available действует true.
- Перед импортом уточни нечитаемые названия и цены у человека. Не придумывай ассортимент, цены, остатки, ссылки или характеристики.
- Если у одной позиции разные цены по объёмам, укажи их отдельными блюдами с объёмом в названии, например «Капучино 250 мл» и «Капучино 350 мл».
- В одной категории используй по одному блюду с данным названием. Название блюда и категория вместе определяют дубликат.
- Один импорт принимает до 100 категорий и 100 блюд. Для большего меню подготовь отдельные JSON-объекты для последовательного импорта.
